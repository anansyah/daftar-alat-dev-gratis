# Daftar Alat Dev Gratis

Kumpulan alat pengembangan perangkat lunak gratis dan open source yang berguna untuk pemula maupun profesional. Silakan tambahkan alat yang Anda rekomendasikan lewat Pull Request.

## Kontrol Versi
- [Git](https://git-scm.com/) - sistem kontrol versi terdistribusi
- [GitHub](https://github.com/) - hosting repositori Git dan kolaborasi

## Editor dan IDE
- [Visual Studio Code](https://code.visualstudio.com/) - editor kode gratis dari Microsoft
- [Neovim](https://neovim.io/) - editor berbasis terminal yang dapat diperluas

## Dokumentasi dan Belajar
- [MDN Web Docs](https://developer.mozilla.org/) - dokumentasi web dari Mozilla
- [Roadmap.sh](https://roadmap.sh/) - panduan jalur belajar pengembangan

## Cara Berkontribusi
1. Fork repositori ini.
2. Tambahkan alat di kategori yang sesuai, dengan format `- [Nama](url) - deskripsi singkat`.
3. Buka Pull Request dengan judul yang jelas.
